# 理科ラボ

中学理科の学習アプリをまとめたポータルです。

- **入口**: [index.html](index.html)
- **力の関係性**: [forces.html](forces.html) — 既存の図解・作図・4択テスト
- **電気回路**: [circuits.html](circuits.html) — 直列・並列・混合回路、シミュレーター、4択クイズ

## 管理と公開

すべてこのリポジトリで管理します。入口を変更するときは index.html、各教材を変更するときは対応するHTMLを編集してください。力の教材の画像はルートに置いたままです。

GitHub Pagesは main ブランチのルートを公開元に設定できます。既に設定済みなら、mainへの反映後に入口がポータルへ変わります。

ローカルでは index.html をブラウザーで開けます。力の教材はCDNのCSS・アイコン・フォントにインターネット接続を使用します。回路教材と入口は外部ライブラリ不要です。

回路教材はPCでの利用に適した1画面構成です。クイズでは正解後に自動で次の問題へ進みます。音は回答操作時に再生します。全画面表示は対応ブラウザーで利用できます。

## 既存の力の教材について

# 理科「力」完全攻略マスター 🚀

中学理科で学習する「力の性質」「作図」「つり合い」「作用・反作用」「力の分解」を直感的な図解とインタラクティブなトレーニングでマスターできるWebアプリケーションです。

---

## 🌟 主な機能

### 1. 4つの定番テーマに対応
* **① 天井・ひも・おもり**：張力・重力・つり合い・作用反作用の基本
* **② 机と本**：机を押す力、垂直抗力、重力の違いを徹底比較
* **③ 2つの物体とひも**：複数物体にはたらく力の伝わり方と3力のつり合い
* **④ 斜面とばね**：重力の斜面平行分力・垂直分力への分解と2方向のつり合い

### 2. 多角的な4つの学習モード
1. **図解探索モード**
   * インタラクティブな図で作用点・向き・大きさを直感確認
   * つり合いや作用反作用、分力のペアをワンクリックでハイライト
   * アプリ作図（カラーベクター）と問題原図（添付そのままの図）の切り替えに対応
2. **文の組み立てモード**
   * 「何が（主語）」「何を（目的語）」引く・押す力かをスロットにはめて組み立てる特訓ゲーム
   * 図には記号バッジのみを表示し、自力で考える力を養う
3. **図解4択テスト（全26問）**
   * 各テーマ別の力・分解・つり合いの4択クイズ
   * 選択肢は1〜4で毎回ランダムにシャッフル
   * 正解時は1秒後に自動で次の問題へテンポよく進行
4. **見分け方の極意（チートシート）**
   * 「同じ物体にはたらく ＝ つり合い」「主語と目的語が逆 ＝ 作用反作用」などの絶対間違えない黄金ルールを整理

### 3. 学習を快適にする機能
* **ダークモード対応**：夜間や長時間の学習でも目に優しいデザイン
* **図の動き ON/OFF**：アニメーションのパルス効果を好みに合わせて切り替え可能
* **全画面表示対応**：授業や集中学習に便利なフルスクリーンボタン
* **ファビコン完備**：ブラウザタブやホーム画面アイコンに対応

## 🚀 GitHub Pages での公開方法
本リポジトリを GitHub Pages でホスティングする場合：
1. GitHub リポジトリの **Settings** > **Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. **Branch** を `main`（または `master`）の `/ (root)` に設定して **Save**
4. 数分で公開URLが発行されます。
